# EUREKA — The Final Block of the Blockchain

A responsive landing page concept for Eureka Protocol.

## Files
- `index.html` — page structure
- `styles.css` — visual design, responsive layout and animations
- `script.js` — navigation, chain buttons, toast notifications and reveal animations
- `assets/eureka-hero.jpeg` — supplied Eureka artwork

## Run
Open `index.html` directly in a browser, or serve the folder with any static web server.

## Important
The chain buttons currently demonstrate navigation to official ecosystem websites.
For the real Eureka product, replace those URLs/actions with your own application routes,
wallet connections, chain switching, token contract address and backend/API integrations.

The X button is a placeholder and should be changed to the official Eureka X profile.
